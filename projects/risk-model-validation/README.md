# 投资组合构建与风险模型验证

基于个人 CQF 学习项目整理的公开研究练习。这里提供重新组织的代码和说明，**不包含考试题目、声明、提交报告、市场数据或原报告的保存输出**。公开整理版修改了实验设计，不能把原报告数字当成本版本重新运行的结果。

## 可复现内容

- 使用协方差矩阵求解允许卖空、权重和为 1、满足目标收益的最小方差组合。示例参数是人为设定，不是资产收益预测。
- 计算正损失口径的正态 VaR/ES 和权重偏导数，以中心有限差分核对导数。偏导改变单个权重，不隐含对其余权重重新平衡。
- 在同一组预测日期上比较滚动标准差、EWMA 和历史日收益分位数缩放三类 99% / 10 个交易观测期风险阈值。
- 输出共同样本上的超限率；另对不重叠收益区间给出 Kupiec 和二项分布参考诊断，并明确它们的独立性假设。

## 运行

Python 3.10+，依赖 `numpy pandas scipy matplotlib`；Notebook 另需 `jupyter nbformat`。从本目录运行：

```bash
python -m pip install numpy pandas scipy matplotlib jupyter nbformat
python analysis.py
python checks.py
jupyter notebook notebooks/analysis_clean.ipynb
```

不传 `--csv` 时，使用固定种子生成的合成价格，**只演示流程，不产生市场结论或投资建议**。Notebook 的 `DATA_PATH = None` 采用同一演示方式。代码不联网，不自动寻找或读取用户的原始资料。

如需使用自己有权使用的行情，显式指定仓库外的本地 CSV：

```bash
python analysis.py --csv /path/outside/repository/prices.csv
```

Windows 路径含空格时加引号。在 Notebook 中将 `DATA_PATH` 改为对应文件路径。

### CSV 数据合同

两列：`date` 和 `close`。`date` 为可解析的日期，必须唯一且严格递增；`close` 必须为有限正数。每行代表一个按交易时序排列的收盘价观测，保持同一标的、币种、时区和复权口径。额外列忽略，缺失值、重复日期和乱序会报错，不自动填充。调用者负责确认交易日完整性；代码中的 10 期表示后续 10 行，**不是 10 个自然日**。完整结果至少需要 `window + horizon + 1` 行数据；尾部尚未实现的未来收益会被排除。

行情来源、授权条件、收盘时点和复权方式应自行记录；本项目不分发或上传数据。不要把真实 CSV、运行输出或个人绝对路径提交到仓库。

## 信息时点与口径

在收盘时点 t，使用截至 t 的收益预测 `-log(P[t+10]/P[t])`，正数表示亏损。滚动法和历史分位数均包括最新收益 r[t]；EWMA 在最初 21 个已观察收益上初始化，之后仅按时间向前递推。所有模型先取共同有效日期，再统计超限；未来收益只用于事后评价。

默认 EWMA 衰减系数为 0.72：最新平方收益的权重是 **1 - 0.72 = 28%**，旧方差权重是 72%，半衰期约 **2.11 个观测期**。更快响应并不保证更低的超限率，也不意味着模型在任何时期都更好。

滚动标准差用 `ddof=1`；EWMA 更新采用零条件均值的平方收益假设。正态法与经验分位数都使用平方根时间缩放；后者因此称为 `historical_scaled`，不能被描述成直接估计了真实的 10 日损失分布。21 个样本估计 1% 尾部非常不稳定，可在代码中修改窗口开展敏感性分析。

默认逐日评价的 10 期收益相互重叠，因此只报告描述性超限率。每隔 10 行抽取一次可以去掉收益区间重叠，但仍不能证明超限事件独立。另列的 `nominal_iid_pvalue` 和 `binomial_band_iid_reference` 仅是独立同分布假设下的参考值，**不是监管交通灯判定，也不是模型通过验证的证据**。小样本检验效力有限；不拒绝原假设不能解释成模型正确。

## 相对原学习版本的公开整理修改

1. 替换题目特定参数、AI 答案对照和报告文字，以独立构造的小型例子展示组合约束与导数核验。
2. 将本地 Excel 文件名依赖改为明确的 CSV 接口和合成数据演示；删除全部历史输出。
3. 去除 EWMA 全样本方差初始化，统一预测时间、历史窗口终点和比较日期，避免前视信息。
4. 统一为正损失 VaR/ES，修正 EWMA 权重、半衰期说明，删除没有证据的模型优劣排序。
5. 用对数似然实现稳健的 Kupiec 计算，处理零次／全部超限；将重叠区间的描述统计与附条件参考检验分开。

这些改变使本版本与原结果不可直接对比。本仓库未重新分析原 S&P 500 数据，也不声称更新后的真实行情超限率、显著性或样本外优越性。

## 验证与限制

`checks.py` 验证组合约束、风险导数的有限差分、追加未来数据不影响过去预测、改变未来价格不影响过去预测、EWMA 初值和更新公式、共同评价日期、Kupiec 边界值及 CSV 输入校验。Notebook 清空输出后保存，执行结果由读者当前环境生成。

模型忽略跳跃、条件偏度、流动性和交易执行等问题；平方根时间缩放、零均值和正态性只是简化假设。本项目展示风险计算和验证设计，不是交易策略，也没有收益或实盘绩效。
