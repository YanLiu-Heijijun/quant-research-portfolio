# 期权 Monte Carlo 定价与方差缩减

基于个人 CQF 学习项目整理的公开数值研究练习。保留 GBM、Euler–Maruyama、Milstein 和对偶变量的数学方法，重新组织为可运行模块和原创说明。**不包含考试题目、声明、原提交报告或其保存输出。** 所有输入都是模型参数，不需要市场数据，也不联网。

## 研究问题

对无分红 GBM 下的欧式看涨与单位现金二元看涨期权，比较模拟价格、抽样不确定性和时间离散的影响。二元期权在终值严格大于执行价时支付一单位现金。

- 精确终值采样：直接从 GBM 对数正态终值分布抽样，没有时间离散误差，**仍有 Monte Carlo 抽样误差**。
- Euler 和 Milstein：按时间步推进路径，以相同 payoff 计算折现均值。
- 解析基准：公开整理版增加无分红 Black–Scholes 普通看涨和二元看涨解析价格。
- 对偶变量：每个时间步使用 z 与 -z 构造路径对，以每对平均 payoff 为一个独立观测。
- 参数情景：波动率、利率、期限共 27 组情景；显示模拟估计的 95% 正态近似区间和解析曲线。

## 方差缩减的正确比较

普通模拟 N 条路径，得到 N 个独立 payoff；对偶模拟仍为 N 条路径，但只有 N/2 个独立 pair 均值。因此必须比较：

```text
普通估计量方差 = 普通 payoff 样本方差 / N
对偶估计量方差 = pair 均值样本方差 / (N/2)
同路径预算方差比 = 普通估计量方差 / 对偶估计量方差
```

代码同时输出独立观测数、总路径数、标准误和估计量方差。原报告中的 3.976 是未调整独立观测数的样本方差比，不能用作同路径预算的估计量改善倍数；该数值不作为本公开版的实验结果。**相同路径数量也不等于相同运行时间**，标准误降幅应和实测时长分开报告。

对偶变量不保证在每一种 payoff 或每个参数下有效，本例只实现 Euler 欧式看涨。标准误和区间衡量抽样不确定性，不能自动覆盖离散偏差、参数错误或模型风险。

## 相对原学习版本的公开整理修改

1. 替换原考试报告全部文字，删除原输出；代码拆为函数、轻量 Notebook 和离线检查。

## 已验证范围

`checks.py` 采用 16,000 条路径、64 步做数值合理性检查，并使用更小规模遍历 27 个参数情景；另核对解析价格、二元 payoff 边界、零波动率极限、标准误公式和同路径预算下的方差比。随机实验检查使用固定种子与宽容差，不把某次 95% 区间覆盖当成恒等式。

这是一项定价与数值方法练习，不含行情预测、Alpha 策略、交易回测、执行系统或实盘表现。无分红、常波动率、常利率 GBM 是简化模型；波动率微笑、跳跃、路径依赖及随机波动率不在实现范围。
